Privacy Policy

Two English Mugs Podcast · last updated 22 October 2026

This policy covers the software the Two English Mugs team uses to publish and look after its own YouTube channel. It is a one-person setup: the software runs on the channel owner's own computers.

What the software reads

  • Public video data from the Two English Mugs channel: titles, descriptions, chapters.
  • Comments on that channel's videos, so the owner can read and answer them.
  • The channel's own viewing figures and watch-time reports.

How we use it

Only to run the channel: to check an upload is correct, to answer comments, and to see which episodes help people. Nothing is sold, rented or shared with advertisers.

What we store

An access token from Google, kept on the owner's own machine, and a local record of which comments have already been seen so the same comment is not reported twice. The token can be revoked at any time from the Google account's security settings.

Who else sees it

Google, because the data comes from its YouTube API. No other company receives it. The software sends no data to the owner's own servers: there are none.

YouTube API Services

This software uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. Data received from the YouTube API is handled only as described on this page, in line with Google's Limited Use requirements, and is never sold or shared with advertisers or data brokers.

Episode PDFs and your email

The episode PDFs are free. To get one you give an email address on our own download page. We use it to send you the PDF you asked for and, occasionally, to tell you about a new episode. Nothing else: it is never sold, rented or shared with advertisers or data brokers.

Where it lives: the address is stored in Cloudflare's key-value store, run by Cloudflare, Inc., which also serves the download link. Cloudflare keeps it as our processor and does not use it for its own purposes. We keep it until you ask us to delete it.

Getting it removed: reply to any email from us, or write to hello@twoenglishmugs.com, and the address is deleted. Occasionally we may email you about a new episode; every one of those emails says how to stop them.

We do not use advertising cookies or trackers on this site, and we do not build a profile of you.

Children

The show is made for adult learners. The software reads no private data about viewers at all, and comment author names are only visible to the channel owner inside YouTube itself.

Your choices

Comment authors can delete their comment inside YouTube at any time. To ask a question about this policy, write to the address below.
